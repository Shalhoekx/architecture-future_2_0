# Roadmap

| Этап                                      | Период     | Основные действия                                               | Результат                                  | Ответственные            | Ресурсы                |
| ----------------------------------------- |------------|-----------------------------------------------------------------| ------------------------------------------ | ------------------------ | ---------------------- |
| **1. Инфраструктурное основание**         | Q1–Q2 2026 | Внедрение Kubernetes, CI/CD, централизованной авторизации (IAM) | Унифицированная среда для сервисов         | DevOps Team              | Облако, лицензии CI/CD |
| **2. Доменное разделение**                | Q2–Q3 2026 | Реализация Data Mesh, выделение доменов Мед, Финтех, AI     | Независимое развитие направлений           | Архитектурная команда    | Kafka, DWH, DataOps    |
| **4. AI-интеграции и аналитика**          | Q4 2026    | Внедрение MLflow и Airflow, подключение AI к медицинским данным | Прогнозы и диагностика в реальном времени  | Data Science + AI        | GPU, Vertex AI         |
| **5. Масштабирование и внешние партнёры** | Q1 2026    | Интеграция Pharma и Electronics через API                       | Расширение экосистемы компании             | Partner Integration Team | API Gateway, SDK       |
| **6. Мониторинг и контроль качества**     | Q1–Q2 2026 | Настройка OpenTelemetry, SLA, дашборды качества                 | Стабильность медицинских и финтех-сервисов | SRE Team                 | Grafana, Prometheus    |

# Обоснование изменений

| Этап                           | Цель                                                   | Влияние на бизнес                                    |
| ------------------------------ | ------------------------------------------------------ | ---------------------------------------------------- |
| **Инфраструктурное основание** | Ускорить выпуск сервисов                               | Сокращение T2M, стабильная среда, скорость внедрения новых бизнес-функций         |
| **Доменное разделение**        | Уменьшить зависимость от DWH и централизованных команд | Рост автономности и скорости разработки. Независимость развития              |
| **Портал самообслуживания**    | Повысить удобство клиентов и партнёров                 | Снижение затрат на поддержку, рост удовлетворённости, клиентский позитивный опыт |
| **AI-интеграции**              | Улучшить диагностику и прогнозирование                 | Повышение точности решений и снижение ошибок         |
| **Масштабирование и партнёры** | Открыть новые источники дохода                         | Расширение экосистемы, интеграция внешних API        |
| **Мониторинг и качество**      | Снизить операционные риски                             | Прозрачность, контроль SLA, повышение доверия        |
